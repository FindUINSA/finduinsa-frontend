# 📱 FindUINSA

FindUINSA is a native Android application designed to simplify the **Lost & Found** process at **UIN Sunan Ampel Surabaya**. The application enables students to report lost or found items, search existing reports, submit ownership claims, and track claim status through a centralized platform.

## ✨ Features

- 🔍 Report lost and found items
- 📦 Browse and search item reports
- 📝 Submit ownership claims
- 📊 Track claim status
- 💬 Real-time notifications
- 👮 Admin verification and claim management
